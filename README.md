# ATS-25 HamTech M0FXB Controller — V0.5

Display/backlight correction only. V0.4 proved the ESP32 firmware remains stable while the panel changed white to black. V0.5 keeps the candidate GPIO14 backlight control LOW after TFT initialization and draws an unmistakable colour-bar test pattern.

Touch, SI473x, encoder, audio and front-end control remain disabled in this build.
